We’re excited to announce version 1.2.0 of the OpenAQ Python SDK. This release brings the SDK up to date with the recently released Python 3.15, delivers some significant speed improvements, and makes changes to how we test the library behind the scenes. 1.2.0 is the third release since the library reached stable.
